抖音开放平台

连接前需要准备

  1. 已获视频上传和发布权限的抖音开放平台应用。
  2. 在服务端设置 DOUYIN_CLIENT_KEY、DOUYIN_CLIENT_SECRET、DOUYIN_REDIRECT_URI。
  3. 回调地址必须与开放平台登记一致，路径为 /api/v1/studio/douyin/callback，并能到达本服务。
  4. 重启服务后连接账号。授权到期需要重新连接。

本地 HTTP 仅供调试。平台若要求 HTTPS 回调，需要部署服务并配置 HTTPS；应用权限以平台实际审核为准。
